Slayer is a physically accurate ray tracer that any agent can drive. It writes plain YAML, reads plain errors and renders on your laptop.

get started ▶ watch the reel
agent session[illustrative session]
youfilm a hillside at moonrise. twelve seconds, warm film stock, a slow score.

agentwrote jobs/moonrise.yaml
$ game run slayer -- assess jobs/moonrise.yaml
[assess error: unknown key, with file:line:column]
agentfixed the key. $ game run slayer -- draw jobs/moonrise.yaml

out/moonrise/ frames + mp4 + score

The contact sheet

Four films, one program, one laptop. Each frame carries its render facts.

A camera with a darkroom attached.

A scene is a set. A shot is a job. Nothing about either needs you to write Go.

  1. 01
    Write the shot

    A set is a world in YAML, measured in metres. A job is the camera, time, soundtrack and outputs.

  2. 02
    Trace the light

    Stills run on the CPU. Metal takes over on a Mac. Long renders resume after an interruption.

  3. 03
    Develop the film

    PNG, MP4 with a synthesized score, or raw linear light you re-expose later.
