# slayer-site

The landing page for [Slayer](https://github.com/janearc/slayer), the open-source Go + Metal ray tracer by Jane Arc.

This site belongs to Jane Arc. Louie Sakoda maintains it, and will transfer it to Jane on request.

## How it works

- `index.html` is the whole page. There is no build step.
- `assets/` holds the reel videos. Keep each one under 10 MB.
- Vercel deploys every push to `main`.
