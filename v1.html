how it works

Write the shot. Trace the light. Develop the film.

Slayer works like a camera with a darkroom attached. A scene is a set, a shot is a job, and nothing about either needs you to write Go.

01 / write

Describe the scene

A set is a world in YAML: geometry, materials, lights, volumes and sky, measured in metres. A job is the photograph or film: camera, size, samples, time, soundtrack and outputs.

02 / trace

Let the light run

Run draw on a job. Stills run on the CPU with no special hardware, and renderer: gpu switches to Metal on a Mac. Long renders pick up where they left off if interrupted.

03 / develop

Get the finished piece

Out comes a PNG, an MP4 with a synthesized score, or a raw PFM of linear light you can re-expose later without re-tracing. Portrait framing is built in, ready for Shorts and Reels.

agent-native

Your agent already speaks slayer.

Everything Slayer needs is plain text and a command line. That makes it a natural tool for Claude, Codex, or any agent that can edit a file and run a shell.

  • Plain-text scenes. Sets and jobs are YAML, so an agent can write a shot the same way it writes code.
  • Errors that point. Unknown keys are refused at their exact source location, so an agent can fix its own mistakes.
  • A catalogue it can read. list shows every scene, smoke, preset, stock, tune and voicing available.
  • Runs locally. No render farm, no API bill. Your laptop is the studio.
# what can i film?
$ game run slayer -- list

# check the job before spending any light on it
$ game run slayer -- assess jobs/first-picture.yaml

# a still, on the cpu
$ game run slayer -- draw jobs/first-picture.yaml

# re-develop the raw light without re-tracing
$ game run slayer -- develop jobs/first-picture.yaml out/first-picture.pfm

# a short film, scored
$ game run slayer -- draw jobs/first-film.yaml
→ out/first-film/  frames + mp4
inside the box

Built like a photographer, checked like a physicist.

darkroom

Light first, look later

Linear light is kept apart from development, so a saved frame can be re-exposed or re-white-balanced without tracing it again.

ninjafilm

Real film stock

Photographic stock, optics and grain are modelled, so every frame carries the character of a real camera.

manufactory

Worlds on demand

Rocks, trees, houses and the rest of what you'd find outside, all generated procedurally.

synth

Scored in sync

A built-in synthesizer writes the soundtrack and keeps the music in time with the picture.

sky

The cosmos, to scale

Volumetric light and astronomical scenes, from a hillside at moonrise to a star wrapped in a Dyson swarm.

burning-trousers

Physics, verified

An independent validation harness checks the physics, so pretty and correct stay the same thing.
